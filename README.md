# Typing Speed Game

A simple typing speed game built with React. Test how fast and accurately you can type!

## Features

* Random typing passages
* Real-time character highlighting
* WPM, accuracy, and error tracking
* 15, 30, and 60-second modes
* Easy, Medium, and Hard difficulty levels
* Restart and New Game buttons
* Best score saved in localStorage
* Dark and light mode
* Responsive design


Open the local URL shown in your terminal.

## Built With

* React
* JavaScript
* CSS
